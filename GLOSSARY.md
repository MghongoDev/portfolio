# Portfolio

The personal site of David Mwandairo, a data engineer and data scientist. Its goal is to win interviews for data roles. Recruiters and hiring managers are the main audience; peers and freelance clients are secondary.

## Language

**Case Study**:
A static write-up page for one project, told as business problem → approach → measurable impact, with links out to the repo and any live demo.
_Avoid_: Project page, blog post

**Featured Project**:
A project promoted to the home page hero section; every Featured Project has a Case Study.
_Avoid_: Highlight, pinned repo

## Design System

**Design system**: the dark "data-made-visible" system the site ships with:
ink `#05080a`, paper `#e9f1ee`, accent `#c8f04b`, display font Space Grotesk,
body font Inter, mono JetBrains Mono, and spring-eased entry choreography.
Re-decorated surgically in this work; it is a reference direction, not a
rebrand to Terminal Luxe (the astro-portfolio system targets Astro 5 and is
out of scope for this Next.js repo).

**Accent**: the site's brand highlight, `#c8f04b` (warm gold). Treated as
sacred under the visual re-decoration: kept, not swapped.

**Spacer**: a vertical rhythm scale applied between sections and components;
the previous ad-hoc `py-*` values are replaced by the scale.
