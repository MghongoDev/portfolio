# Portfolio

The personal site of David Mwandairo, a data engineer and data scientist. Its goal is to win interviews for data roles. Recruiters and hiring managers are the main audience; peers and freelance clients are secondary.

## Language

**Case Study**:
A static write-up page for one project, told as business problem → approach → measurable impact, with links out to the repo and any live demo.
_Avoid_: Project page, blog post

**Featured Project**:
A project promoted to the home page hero section; every Featured Project has a Case Study.
_Avoid_: Highlight, pinned repo
