# ADR 0003: Hero chart recedes behind name

## Decision

Move the hero chart canvas from full-bleed to the bottom quarter of the viewport.

## Reason

The chart competed with David's name for attention. By shrinking the canvas and anchoring it at the bottom, the name becomes the clear focal point while the chart reads as a restrained background texture.

## Trade-off

The chart no longer reads as a primary element on narrow screens, but that was the stated goal. The reduced-motion static frame keeps the chart visible even when motion is disabled.
